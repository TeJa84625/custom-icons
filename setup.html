Icons Setup

Installation Guide

1. Include Stylesheet

Add the core stylesheet link inside your HTML <head> tag. This sets up the base CSS variables and initial scaling.

<link rel="stylesheet" href="ci-icons.css">

2. Usage Example

Place an <i> tag anywhere in your markup with the specific icon name. You can use standard inline styles for colors and sizes.

<i class="ci ci-user" style="color: #2563eb;"></i>

3. Smart Loader Script

Add the smart loader script at the end of your body tag. This powers the per-icon lazy checking and background updating features.

<script src="ci-loader.js" defer></script>
