Icons Setup

CI Icons Documentation & Installation Guide

A lightweight, lightning-fast, mask-based SVG icon utility library with zero layout shift and offline caching support. Live Test

1. Include the Stylesheet

Add the core ci.css stylesheet, ci.js script inside your HTML <head>. This establishes baseline dimensions, CSS custom properties, sizing multipliers, rotations, color modifiers, and keyframe animations.

<link rel="stylesheet" href="https://ci-icons.vercel.app/ci.css">
<script src="https://ci-icons.vercel.app/ci.js" defer></script>

2. Basic & Advanced Icon Usage

Place an <i> tag with the base ci class and a specific icon name (e.g., ci-user). You can combine multiple utility modifiers for sizes, colors, shadows, and animations:

<i class="ci ci-user ci-lg ci-primary ci-shake ci-shadow"></i>

Tip: Icons automatically inherit text color (currentColor), making them style seamlessly with buttons, links, and text headings.

3. Smart Loader Scripts (Offline Caching) [Optional]

Add your loader scripts at the end of your <body> tag:

Stores icon SVGs directly into localStorage. This allows icons to render instantly and work seamlessly even when the user is completely offline, while auto-syncing updates from the cloud when online.

<script src="https://ci-icons.vercel.app/ci-loader.js" defer></script>

4. Complete Style & Modifier Reference

Combine any of the following modifier classes with your .ci .ci-[name] element:

Sizing Utilities

Scale icons relative to the current font size:

  • .ci-xxs (0.5em)
  • .ci-2xs (0.625em)
  • .ci-xs (0.75em)
  • .ci-sm (0.875em)
  • .ci-lg (1.33em)
  • .ci-xl (1.5em)
  • .ci-2xl (2em)
  • .ci-3xl (2.5em)
  • .ci-4xl (3em)
  • .ci-fw (Fixed width alignment)

Color Modifiers

Semantic & vibrant predefined color classes:

  • .ci-primary
  • .ci-secondary
  • .ci-success
  • .ci-danger
  • .ci-warning
  • .ci-info
  • .ci-light / .ci-dark
  • .ci-red, .ci-blue
  • .ci-green, .ci-yellow
  • .ci-purple, .ci-pink
  • .ci-indigo, .ci-teal, .ci-orange

Animations & States

Bring your icons to life with built-in keyframes:

  • .ci-spin (Continuous 360 ° spin)
  • .ci-pulse (Breathing opacity/scale)
  • .ci-bounce (Vertical jumping effect)
  • .ci-beat (Pulsing heartbeat scale)
  • .ci-fade (Smooth entry fade - in)
  • .ci-shake (Vibrating error alert)
  • .ci-flash (Blinking indicator)
  • .ci-float (Gentle floating motion)
  • .ci-glow (Dynamic shadow glow)

Transforms & Depth Shadows

Adjust alignment, orientation, and mask-aware drop shadows:

  • .ci-rotate-90 / 180 / 270
  • .ci-flip-horizontal / .ci-flip-vertical
  • .ci-align-baseline / -top / -bottom / -middle
  • .ci-shadow-sm, .ci-shadow, .ci-shadow-lg
  • .ci-interactive (Hover zoom cursor pointer)
  • .ci-disabled (Dimmed, unclickable state)
