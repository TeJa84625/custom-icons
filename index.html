▣ CI Icons Quickstart Setup Guide

1. Include Stylesheet

Add the core stylesheet link inside your HTML <head> tag:

<link rel="stylesheet" href="ci-icons.css">

2. Usage Example

Place an <i> tag anywhere in your markup with custom styling:

<i class="ci ci-user" style="color: #2563eb;"></i>

3. Smart Loader Script

Add the smart loader script at the end of your body to enable per-icon lazy checking & background updating:

<script src="ci-loader.js" defer></script>
