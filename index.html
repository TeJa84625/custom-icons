About CI Icons

I built CI Icons specifically for custom web projects that require complete design control without the bloat of massive icon fonts. Traditional icon libraries force users to download hundreds of icons even if they only use five.

CI Icons solves this by utilizing a modular CSS architecture and a JavaScript-powered smart loader. This ensures that your application only fetches and renders the precise SVGs needed on the active page, keeping your load times lightning fast.

Installation & Setup

Getting started with CI Icons takes less than a minute. Follow these three simple steps:

1. Include Stylesheet

Add the core stylesheet link inside your HTML <head> tag to establish base icon dimensions and variables:

<link rel="stylesheet" href="ci-icons.css">

2. Usage Example

Place an <i> tag anywhere in your markup. You can customize the color and size using standard inline styles or utility classes:

<i class="ci ci-user" style="color: #2563eb;"></i>

3. Smart Loader Script

Add the smart loader script at the end of your <body>. This is the magic behind the library.

<script src="ci-loader.js" defer></script>

How the Smart Loader Works

By deferring ci-loader.js, the script runs immediately after the DOM is parsed. It scans the page for any element containing the ci class. For every matching element, it reads the specific icon identifier (e.g., ci-user) and injects the corresponding SVG data directly into the background-image or inner HTML of the tag.

Benefits:

  • Zero Render Blocking: The initial page paints instantly.
  • Per-Icon Lazy Checking: Only icons present in the DOM are downloaded.
  • Background Updating: If new icons are injected dynamically via AJAX or React/Vue state changes, a MutationObserver catches them and loads the icons on the fly.
